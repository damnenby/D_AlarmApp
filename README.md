# D_AlarmApp

A simple Android alarm clock app for the Mobile Systeme exercise. The app lets the user select an alarm time, set or cancel the alarm, snooze it when it rings, and receive a notification with the next alarm time.

## Features
- Alarm setup with TimePicker
- Alarm cancellation
- Snooze with configurable duration
- Notification after snooze
- Alarm sound playback
- Basic background and lock screen handling
